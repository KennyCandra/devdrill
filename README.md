# BugHunt

> Working name. Under construction — see [docs/V1_PLAN.md](docs/V1_PLAN.md).

Practice the interview skills that matter in the AI era, locally in your browser:

- **Debug:** find and fix the bug so the tests pass.
- **Feature:** add a feature without breaking what already works.
- **Review** _(coming in v1.1)_: review a PR and catch the planted issues.

## Development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run check
```

`npm run check` runs lint, format check, typecheck, and tests.
